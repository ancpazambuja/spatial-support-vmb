# Reproducibility checklist

Complete before submitting the repository URL to the journal.

- [ ] Public repository URL works in a logged-out browser.
- [ ] All source files and code comments are in English.
- [ ] License is valid and compatible with third-party dependencies.
- [ ] README installation and quickstart instructions have been tested from a clean environment.
- [ ] Container base image and key dependencies are pinned or otherwise reproducibly specified.
- [ ] Smoke test runs without restricted data.
- [ ] Research dataset restrictions and access procedure are explicit.
- [ ] All reported experiment configurations and seeds are included.
- [ ] Training, evaluation, statistical-analysis, and figure/table scripts are documented.
- [ ] Inputs, outputs, units, shapes, defaults, and failure behavior are documented.
- [ ] Expected outputs are described, including tolerances for nondeterministic results.
- [ ] No restricted data, secrets, local paths, or unlicensed assets are committed.
- [ ] Repository URL is included in the manuscript.
- [ ] A versioned release is created for the submission code.
- [ ] The exact release has been tested and corresponds to the code described in the paper.
