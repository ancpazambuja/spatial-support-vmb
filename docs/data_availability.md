# Data availability and restrictions

## Research Datasets

The original datasets used for the paper are not distributed in this repository because access is restricted.


### Access Procedure

In order to ask for full access, email me (see Contacts page).

## Quickstart Data

A small subset of the original dataset is provided for installation and sanity check.
These quickstart data can be found in ./data/shallower and ./data/deeper directories.

## Reproducibility impact
Full reproducibility of paper results can be achieved just with the not provided full dataset.
