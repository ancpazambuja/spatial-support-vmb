
# Data Directory

See [Data availability](../docs/data_availability.md) for access restrictions and other information.


## Shallower Dataset 

This dataset is a small subset of $D_{s2}$ dataset referenced in the paper "On the Calibration of Spatial Support in Deep Learning-Assisted Velocity Model Building" - or $S2$ dataset of the paper "Deep-tomography: Iterative Velocity Model Building with Deep Learning" used as test bed. 

## Deeper Dataset 

This dataset is a small subset of $D_{deep}$ dataset referenced in the paper "On the Calibration of Spatial Support in Deep Learning-Assisted Velocity Model Building".
