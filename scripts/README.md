# Scripts

Place or document the verified entry points for:

- training each architecture/configuration;
- evaluating saved checkpoints;
- calculating metrics and confidence intervals;
- performing pairwise statistical comparisons;
- regenerating supported paper tables and figures.

Use explicit command-line arguments or versioned configuration files. Avoid machine-specific absolute paths. Each script should provide a help message and document its inputs and outputs.

Do not add placeholder scripts that appear to work but silently skip scientific steps.
